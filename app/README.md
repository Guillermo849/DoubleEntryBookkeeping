# DOUBLE-ENTRY BOOKKEEPING a Personal Monthly Expenses App
## The objective
The end goal of this project is not just to create an application but to learn and practice 
good standards and disciplines of Clean Coding.
To be proud of the code that we have written, to gives us the courage to enter other projects 
and to be able to start to know our worth.

## Enunciado
El programa consiste en una aplicación de móvil donde se añadiran
entradas de un Gasto o Ganancia.
Tanto los Gastos como las Ganacias tendrán distintas Categorías
y Subcategorías. Estas vendrán de base y/o podrán ser añadidas por el usuario.
Se podrán filtrar por fecha y categoría.
Adicionalmente se podrán establecer Gastos y Ganancias mensuales/anuales.

Las entradas se guardarán en una Base de Datos, el cual podrá
ser exportada en varios formatos (csv, json, etc.) y/o se podrá realizar una
copia de seguridad a Drive o a un servidor.

Al iniciar, la aplicación no deberá de tardar más de 1,5 segundos en
inicializarse. Mostrará de base el Total de Gastos, Ganacias y lo
Ahorrado del mes actual. La Vista Inicial se podrá elegir de las
Vistas de Base, las cuales se verán  en un Menú de lado.
